**ttencate/harmonograph** (https://github.com/ttencate/harmonograph), which is
licensed under the MIT License; its license text ships in that repository's
`LICENSE` file.

The Python implementation in `harmonograph_tab.py` was written for this
repository; no upstream source code was copied. Attribution is kept because
the curve model and parameterization come from the upstream work.
