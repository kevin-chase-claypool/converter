# Vector Trace tab - third-party notice

The Vector Trace tab is an independent outline tracer: Otsu or manual
thresholding, marching-squares boundary extraction, Douglas-Peucker
simplification, Chaikin smoothing, and optional angled hatch fill. It is
inspired by the tracing role of tools such as Potrace and vpype-vectrace, but
no code from them or any other tracer was copied.
