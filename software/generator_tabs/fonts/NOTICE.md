# Hershey simplex font data - notice

`futural.jhf` is the Hershey "Simplex" vector font, converted to `.jhf` format
by James Hurt and distributed by Kamal Mostafa's hershey-fonts project
(https://github.com/kamalmostafa/hershey-fonts, file `hershey-fonts/futural.jhf`).

Use terms carried with that distribution:

- The Hershey Fonts were originally created by Dr. A. V. Hershey while working
  at the U.S. National Bureau of Standards.
- The format of the font data in this distribution was originally created by
  James Hurt, Cognition, Inc.
- The data may be used by anyone for any purpose, commercial or otherwise,
  with those acknowledgements distributed with it. It may be converted into
  any other format except the US NTIS format.

This repository keeps the data in its original `.jhf` format and parses it at
runtime; the parsing code in `_hershey.py` was written for this repository
from the published format description and does not copy the upstream C code.
