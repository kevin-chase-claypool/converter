# Snowflake tab - third-party notice

The Snowflake tab is an independent dendritic branch generator, inspired by
the snowflake art of **vishnubob/snowflake**
(https://github.com/vishnubob/snowflake), which is licensed under the MIT
License; its license text ships in that repository's `LICENSE` file.

The upstream project is a mesoscopic lattice-growth simulation (Gravner and
Griffeath's ice-crystal model) with PyPy and potrace requirements. This tab
does not reproduce that model; `snowflake_tab.py` is a simpler radial branch
generator written for this repository, and no upstream source code was copied.
