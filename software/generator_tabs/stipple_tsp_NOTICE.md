# Stipple / TSP tab - third-party notice

The Stipple / TSP tab is an independent implementation of two classic
techniques: density-weighted stippling in the spirit of Secord's weighted
Voronoi stippling (approximated here with weighted k-means/Lloyd relaxation),
and TSP art (a single line through every stipple, ordered by greedy nearest
neighbour with optional 2-opt improvement). No upstream code was copied.
