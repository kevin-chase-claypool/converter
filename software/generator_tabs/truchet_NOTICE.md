# Truchet tab - third-party notice

The Truchet tab implements the classic Truchet tile concept: a square grid
whose tiles carry two quarter-circle arcs or one of two diagonals, so adjacent
tiles meet at their edge midpoints. The concept is public domain and is not
copied from any repository.

The r/plotterart Truchet repositories surveyed on 2026-10-06 had no license
file, so no code from them was used; `truchet_tab.py` is an independent
implementation written for this repository.
