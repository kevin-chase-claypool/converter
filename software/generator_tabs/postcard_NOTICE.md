# Postcard tab - third-party notice

The Postcard tab re-implements the layout concept of
**cadin/plotter-postcard** (https://github.com/cadin/plotter-postcard), which
is released under the Unlicense (public domain dedication); its license text
ships in that repository's `LICENSE` file.

The Python implementation in `postcard_tab.py` was written for this
repository; it keeps the plottable postcard back (border, centre divider,
stamp box, address guide lines) and draws its own caption/address text with
the bundled Hershey font.
