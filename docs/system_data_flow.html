1. Normal plotting: artwork to physical mark

M3 and M5 are interpreted by grblHAL and become an isolated pin state at the toolhead; they are not forwarded as G-code text. The fixed G4 dwell is the initial open-loop settle time.

2. Startup P100: home, magnetic registration, and work coordinates

The installed GP27 return remains at LIMA; the illustrated PRB path is a candidate, gated by F-08. One GP27 edge never means “center”: P100 owns coordinate capture and all centroid/index calculations.

3. Toolhead lifecycle: M3/M5, force control, and service home

Force sensing and correction remain local to the toolhead; the host and motion controller do not enter that real-time loop. Normal M5 is not an absolute position reference.

4. Fault and recovery: every unsafe input reaches a safe, observable end state

Fault paths do not retry automatically. A recovery action starts a new controlled attempt after the operator has inspected the reported condition.

5. Bench and commissioning: calibration information is kept separate from a drawing job

This preserves the separation between measured, explicitly accepted calibration and the fresh baseline used at boot. A normal M3/M5 cycle never writes the profile.

Authoritative contracts and wiring: integration interfaces, wiring table, toolhead control, and P100 magnetic registration.
