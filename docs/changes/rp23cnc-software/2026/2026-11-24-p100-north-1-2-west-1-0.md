# Move the P100 registered pen 1.2 mm north and 1.0 mm west

## Summary

The P100 axis-centre correction moves from X `2.30`, Y `0.31` to X `1.30`,
Y `1.51`. At the surveyed centre centroid the XY registration write becomes
`G10 L20 P1 X-1.30 Y-30.9992`.

## Reason

The operator reported another `HOME + REGISTER` result in which the parked pen
needed to move 1.20 mm north and 1.000 mm west. P100 subtracts the correction
from `sensor_to_pen`, so increasing the correction moves the registered pen
east/north and decreasing it moves the pen west/south.

## Implementation

The requested movement was applied to the latest tracked source frame:

```text
axis_center_correction_x = 2.30 - 1.00 = 1.30
axis_center_correction_y = 0.31 + 1.20 = 1.51
```

The measured `sensor_to_pen` vector remains unchanged at `(0.0, -29.4892)`.
The local P100 macro is 15,819 bytes with SHA-256
`DABBA2E165B02A7752E1510C330DFDE0D1B9105BBAB3C31E628B5CE554C8AA8F`.

## Verification

- `tools\validate_homing_macro.py`: P100/P115 contract passed with the new
  pinned constants.
- `tools\check_macros.py`: all 17 repository macros parse-safe.
- `Test-NetConnection 10.10.10.2 -Port 21` and `-Port 23` both returned
  `False`, so the controller file could not be read or replaced.
- Physical acceptance remains pending until the macro is uploaded and
  `G65 P113` is repeated.

## Struggles and rejected approaches

The controller was offline, so the currently deployed P100 file could not be
read. This revision therefore applies the requested delta to the latest
tracked `2.30 / 0.31` source frame. If the controller still holds the earlier
`1.45 / 1.01` file, upload this complete revision before using the result;
otherwise the source and machine would remain on different bases.

Changing `sensor_to_pen` was rejected because it would corrupt the measured
TMAG-to-pen geometry. The requested movement belongs in the registration
correction, not the host converter or artwork offsets.

## Risks and follow-up

- Confirm the controller is running the `2.30 / 0.31` base before treating the
  deployed movement as exactly 1.2 mm north and 1.0 mm west.
- After upload, run `G65 P113`, confirm the pen is centered on the embedded
  magnet, and rotate the bed under the lifted pen.
- If the remaining error changes with bed angle, record the A0/A180 vectors;
  a constant registration correction cannot remove runout or an off-axis
  centre magnet.
