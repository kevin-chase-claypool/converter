# Add A-axis command-rate equations to the report

## Summary

The systems integration report now derives the tangential pen speed produced by
a commanded A-axis rate. The equations show why the original
`$113=80000` motor deg/min setting requested 21.47 m/min at the 185 mm rim and
why the verified `20000` motor deg/min correction reduced that request to
5.37 m/min.

The section also records the later `30000` motor deg/min limit and distinguishes
its current evidence: the 100 mm full-revolution test passed, while the
160 mm station has not been rerun at that setting.

The regenerated report also incorporates the already-reviewed pre-correction
mandala photograph and the adjusted completed-plot crop that were present in
the working tree. Keeping those sources and outputs in the same commit makes
the DOCX and PDF reproducible from the checked-in assets.

The first equation build regenerated the DOCX from Markdown and dropped six
edits that existed only in Word. Recovery compared the pre-equation document
with its parent commit and the current Word-saved document with the equation
commit. The six exact prose corrections are now recorded in the canonical
Markdown as well as the rebuilt DOCX and PDF.

## Implementation

The canonical Markdown uses standard display-math delimiters. The report builder
converts each labeled math block from LaTeX to MathML, then uses Microsoft
Office's `MML2OMML.XSL` stylesheet to insert a native, editable Word equation.
The equation-producing JavaScript helper is retained so the DOCX can be rebuilt.
The Figure 3 source image and its caption link are retained with the report
assets, and Figure 7 uses the reviewed crop generated by the report builder.
